Политика обработки персональных данных

Дата последнего обновления: 29 апреля 2026 г.

1. Общие положения

Настоящая Политика конфиденциальности (далее — «Политика») регулирует порядок обработки персональных данных пользователей сервиса Curl Stat Pro, предоставляемого самозанятым Ильиным Андреем Вячеславовичем (ИНН 772158890739, далее — «Оператор»).

Политика разработана в соответствии с требованиями Федерального закона от 27.07.2006 № 152-ФЗ «О персональных данных».

2. Какие данные мы собираем

  • Telegram user ID (числовой идентификатор)
  • Имя пользователя в Telegram (username), если он указан и является публичным
  • Данные, которые пользователь вводит самостоятельно (статистика матчей, данные команд и игроков)
  • Дата и время оплаты подписки, сумма транзакции

Мы не собираем: ФИО, адрес, номер телефона, данные банковских карт (платёж обрабатывается платёжным агрегатором Robokassa).

3. Цели обработки данных

  • Идентификация пользователя и предоставление доступа к функциям сервиса
  • Хранение введённых пользователем данных (статистика матчей)
  • Обработка и подтверждение оплаты подписки
  • Обратная связь и поддержка пользователей

4. Правовое основание

Обработка персональных данных осуществляется на основании согласия пользователя (ст. 6 ФЗ № 152-ФЗ), выражаемого путём добровольного начала использования сервиса.

5. Передача данных третьим лицам

  • Robokassa — платёжный агрегатор. Передаются только данные, необходимые для проведения платежа.
  • Telegram — платформа, через которую работает сервис.
  • Государственных органов — в случаях, предусмотренных законодательством РФ.

6. Хранение данных

Данные хранятся на защищённых серверах. Срок: весь период использования + 3 года после прекращения.

  • Потребовать исправления или удаления данных
